01 수집하는 정보와 수집 방식

프로 넵퍼는 다음 세 가지만 다룹니다.

  • 변환 요청 텍스트 — 사용자가 입력창에서 변환 버튼을 눌렀을 때, 그 시점에 선택된 문구만 처리 대상이 됩니다. 페이지의 다른 내용이나 사용자가 변환을 요청하지 않은 텍스트는 읽거나 전송하지 않습니다.
  • API Key (선택 사항) — OpenAI·Anthropic·Groq 중 본인 키를 직접 등록해서 쓰는 경우에만 저장됩니다. 무료 플랜(Groq 기반)을 쓰면 이 값 자체가 필요 없습니다.
  • 기기 식별자 — 무료 플랜의 하루 사용 횟수를 세기 위해, 설치 시 브라우저 안에서 무작위로 생성되는 값입니다. 이름·이메일·구글 계정 등 어떤 개인 정보와도 연결되어 있지 않습니다.

02 정보가 흘러가는 경로

등록한 API 공급자에 따라 두 가지 경로 중 하나로만 처리됩니다.

본인 API Key 등록 (OpenAI / Anthropic / Groq) 브라우저 → 해당 공급사 서버로 직접 전송
무료 플랜 (API Key 불필요) 브라우저 → 저희 Cloudflare Worker → Groq

두 경로 모두 텍스트는 변환 처리를 위해서만 전달되며, 저희가 운영하는 서버(Cloudflare Worker)는 요청을 그대로 중계할 뿐 텍스트 내용을 저장하거나 로그로 남기지 않습니다. 무료 플랜 서버는 "오늘 몇 번 썼는지"와 "어떤 톤을 골랐는지"만 기기 식별자·톤 이름 단위로 집계하며, 이 집계에는 원문이나 변환 결과가 포함되지 않습니다.

변환된 텍스트가 실제로 처리되는 곳은 사용자가 고른 AI 공급사의 서버입니다. 각 공급사는 자체 개인정보처리방침에 따라 데이터를 처리하며, 저희는 이 처리에 관여하지 않습니다.

04 권한을 요청하는 이유

설치 시 요청하는 권한은 기능 동작에 필요한 최소 범위입니다.

  • 모든 사이트 접근 — 어떤 웹사이트의 입력창에서든 변환 버튼을 띄우기 위해 필요합니다. 사용자가 변환을 요청하기 전까지는 아무 것도 읽거나 전송하지 않습니다.
  • storage — API Key와 톤 설정을 브라우저에 저장하기 위해 필요합니다.
  • scripting — 입력창 옆에 변환 버튼 UI를 그리기 위해 필요합니다.
  • webNavigation — 페이지 안의 iframe(예: 메일 작성창)이 열릴 때 그 안의 입력창에도 변환 버튼을 띄우기 위해 필요합니다. 방문 기록을 저장하거나 외부로 전송하지 않습니다.

05 보관 기간과 삭제

  • API Key·톤 설정은 확장 프로그램을 삭제하거나 직접 지울 때까지 이 컴퓨터에만 남아 있습니다.
  • 무료 플랜의 기기 식별자·일일 사용 횟수는 매일 자동으로 초기화되며, 26시간 뒤 자동 만료됩니다.
  • 변환을 요청한 텍스트 자체는 처리 즉시 응답에만 쓰이고 별도로 저장되지 않습니다.
